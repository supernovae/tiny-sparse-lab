# Tiny Sparse Lab

Tiny Sparse Lab is an installable Python/PyTorch **architecture-learning laboratory**. Milestone 0.1 implements a transparent dense causal decoder and a reproducible local training workflow; it is not a production training framework and does not yet implement MoE, Engram, or other sparse mechanisms.

Install with `uv sync --locked --dev`, then run `uv run sparselab --help`.

The full getting-started workflow, architecture notes, data attribution, and dashboard documentation are added with the runnable stages.
