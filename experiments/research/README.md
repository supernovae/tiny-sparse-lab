# Research definitions and outputs

Current experiment definitions belong in [Kybern Workshop](https://github.com/supernovae/kybern-workshop). Lab contains execution code and tiny maintained test fixtures, not a personal experiment archive.

Generated results belong under `WORK/experiments/<experiment>/<attempt>`, outside this checkout. Select `WORK` with `--work-dir` or `SPARSELAB_WORK_DIR`; the default is `$XDG_DATA_HOME/sparselab` or `~/.local/share/sparselab`. This directory is not an output destination.

[Prior research records](https://github.com/supernovae/tiny-sparse-lab/tree/9d4c840ef1f102becf27532c2548c505c2ed35a6/experiments/research) and [prior generated evidence](https://github.com/supernovae/tiny-sparse-lab/tree/9d4c840ef1f102becf27532c2548c505c2ed35a6/artifacts) remain available at their original Git revision. They were not copied to Workshop and grant no current execution authority. Existing external work directories and held runs are unchanged.
