The [path map](path-map.json) records every original path, retained destination,
SHA-256 and byte count. This relocation preserved **156 files / 5,886,477 bytes**
exactly, including protocols, source declarations, reports, receipts and raw
panels. It removed **16 obsolete Python study helpers**; their original paths,
digests and the recoverable Git revision remain in the map. No old runner or
compatibility alias is provided. Archived YAML/JSON declarations are retained
provenance, not supported launch templates.

The same map also preserves **35 historical Kernel Memory Lab packet files /
116,252 bytes**, relocated without modification. Its total is **193 retained
files / 6,041,772 bytes** and 20 deleted research helpers. The
[current preparation packet](../kernel-memory-lab/card05-base-50m/current/README.md)
is the sole current operator path; B11–B17 result records remain in the active
project as truthful historical evidence. No stopped ledger is changed or reset.

Embedded links, source paths and historical hashes have deliberately not been
rewritten inside archived files. Resolve an old repository path through the map;
for an old relative link, first resolve it relative to that record's original
path. A path absent from the map retains its original repository/external meaning.
A missing machine-local checkpoint or corpus remains unavailable; this archive
neither acquires nor reconstructs it. Git can recover deleted helper source at
the recorded revision, but current-code replay is not claimed.

No archived report establishes a new promotion, current execution approval,
new source rights, platform qualification or an accepted useful model. Failed,
negative and unavailable observations remain part of the record.

The packaged dense and TinyStories `learning_reference` catalog identities stay
unchanged because historical lifecycle bindings depend on their bytes. Their
`recipe: null` entries are inert evidence references, not available execution
recipes; removed helper paths are historical provenance only.

Four superseded Kernel Memory Lab corpus-scale executable helpers were also
removed and indexed with their original hashes. The collected review indexes,
scores, corpus bytes and stopped attempt findings remain unchanged.

The two superseded 50M launch/preparation packet documents are archived under
`kernel-memory-lab/` as well. The active route is the current packet linked above.
