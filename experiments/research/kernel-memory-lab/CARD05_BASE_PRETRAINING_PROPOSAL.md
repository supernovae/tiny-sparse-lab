## Prospective base evaluation

[Profile v1](CARD05_BASE_EVALUATION_PROFILE_V1.json), SHA-256 `bb4c1b719b29fa96c4429516022a5038f0e3595b9d8ef63394bf0a17a5c6851d`, binds **24** existing held-out document/family IDs, source content hashes and tokenizer offsets: four documents per stratum in each of validation and test. Each slice has 257 input tokens and exactly 256 next-token loss targets: **3,072 validation and 3,072 test targets**. Score all 12 validation slices at the 11 declared checkpoints; select the earliest verified checkpoint with lowest finite token-weighted validation loss, then open the 12 test slices once. Score the same profile against the exact selected C05-N1 v2 checkpoint as a matched historical control; do not rewrite its old validation or 0/200 result.

For practical language behavior, run **eight** 64-token plain-prose prompts from fixed general/explanatory held-out slices on each selected checkpoint (16 greedy calls, at most 64 new tokens each, **1,024 requested generated tokens** total). Independently rate topical continuity, grammatical coherence and repetition on exact raw outputs, without `Question:` or role delimiters. Separately score **24** fixed within-stratum, different-family true-versus-decoy 32-token continuation pairs per checkpoint by length-normalized teacher-forced likelihood; that is 3,072 scored utility target positions across both checkpoints and **zero generation** for utility. The full profile uses 46,080 scored evaluation targets and at most 55,000 forward input positions, plus the bounded generated positions. Report every failure or empty output. A continuation can be good without obeying an instruction; the frozen 200-item correctness and format scores remain separate, unchanged and **not rerun** here. This profile cannot qualify a reader or unblock Card 06.

The prospective decision rule is deliberately a **base-learning** rule, not a replacement Card 05 gate: continue to a separately declared instruction-format experiment only if the new checkpoint has finite loss, at least **10% lower token-weighted test loss than the matched v2 checkpoint on these exact slices**, prefers the true continuation on at least **18/24** utility pairs with at least **four** more correct than v2, and has at least **6/8** coherent, relevant, nonrepetitive prose continuations after blind review. If loss improves but utility/prose do not, inspect data cleaning, recipe and model-scale mismatch before another tranche. If loss and utility both stall or regress under this broader supply, stop 341M-scale expansion pending a smaller-model or architecture/optimization comparison. Passing is reason to test instruction adaptation, **not** evidence of instruction compliance or Card 06 eligibility.
