Scope: the five `serving_only=true` jobs in `.github/workflows/ci.yml`, using the unchanged `TESTS` and `COLLECTIONS` in `tools/kernel-memory-lab/ci-guard/run_job.py`. This is a static/offline audit, not hosted Linux or macOS qualification.

Runner logs also sit outside the job root. C05-I8 observed Linux `/opt/hostedtoolcache` and macOS `/Users/runner/hostedtoolcache` and `$HOME/.local/bin`. | Checkout is sampled in the lab; other provider writes are time-bounded and observed through before/after `statvfs`, path and version receipts.
