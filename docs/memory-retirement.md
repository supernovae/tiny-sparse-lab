# Memory-injection active-copy retirement

This slice removes eight memory-injection assets and four shared context inputs
from active Lab paths. The [exact record](memory-retirement.json) preserves their
original byte identities and maps every file to Workshop at
`acf5f61fe4b80f31ba4b2e1db4f37a0f25b0f426`. Before removal, all twelve originals
matched that merged archive byte-for-byte, including size, SHA256 and Git blob.
The [earlier closure](memory-identity-closure.json), context audit and context
retirement records remain unchanged historical inventories.

## Replacement guarantees

The removed personal test asserted the original matrix/study hashes and historical
receipt selection by planning seven original input files. Its personal input
ownership now resides in Workshop. The
[fixed expectations and native acceptance procedure](https://github.com/supernovae/kybern-workshop/tree/acf5f61fe4b80f31ba4b2e1db4f37a0f25b0f426/acceptance/memory-injection-identity)
retain those original hashes, the selection mode and all nine ordered config
identities. Lab owns the existing native reader and verification command.
Workshop #36's reviewed merged-source acceptance covers Lab `d7228be7`; the
retirement candidate requires its own exact-head acceptance, recorded separately
in the retirement PR evidence. An old candidate pass is not a new candidate pass.

| Former local guarantee | Replacement and limit |
| --- | --- |
| Exact personal-study hashes and historical selection | Fixed Workshop expectations checked by native `study report --identity-expectations --candidate-commit` for each explicitly accepted candidate. This is point-in-time personal acceptance, not perpetual Lab CI coverage. |
| Generic normalization and identity selection | `test_study_identity.py` retains fixed neutral vectors, relocation, both selection modes, mismatched identities and nondefault/allocation-manifest refusal. |
| Public expectation/provenance enforcement | `test_study_identity_acceptance.py` retains hermetic public positives, exact/schema refusals, committed full-package binding, byte mismatch and real dirty/untracked cases. |
| Original bytes and retirement inventory | Pre-removal comparison to pinned Workshop originals; local tests bind unchanged closure metadata and check the twelve paths remain absent. These local tests do not fetch or verify remote bytes. |

The personal test is removed only with this explicit transfer of its guarantee.
No personal declarations/cards are hidden in neutral fixtures. The historical
reader is unchanged; removing active files does not remove verification behavior.
Future reader/mode removal still requires a separately reviewed replacement map
and coordinated coverage. Future accepted candidates need explicit acceptance
against the unchanged personal expectations; this change adds no network CI,
scheduler, silent skip or permanent compatibility promise.

## Evidence and scope limits

All four shared context inputs are included, so the earlier context retirement's
30 removed plus four temporarily retained assets are now all archived-only.
Its original 39-entry ledger, guide and frozen scientific results keep their
original bytes and paths. Historical references resolve through the disposition
maps, not by rewriting their recorded hashes.

Tokenizer/prepared payloads that were missing before migration remain unavailable.
Native report verification does not train, load a model, replay historical jobs,
qualify an installed runtime or establish scientific quality. Retained report
bundles and logs are host-local evidence; their inventories do not provide remote
access or guaranteed durability. Reproduction requires current interfaces and new
experiment identities, with separately authorized inputs and runtime work.

Path-domain allocation coverage/scientific constants and the other remaining P1
families are outside this slice. Lab #157/#158 remain partial. External review and
ordinary PR CI must assess this retirement; no self-clearance or merge is implied.
