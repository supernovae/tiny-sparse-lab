# TinyStories recipe location

The CPU microlab recipe is maintained in the optional
[Workshop TinyStories microlab](https://github.com/supernovae/kybern-workshop/tree/main/examples/tinystories-microlab).
Its source declarations and recipe-specific instructions are no longer owned by
Lab. The [disposition record](tinystories-retirement.json) preserves the original
file identities and exact destination commit.

Lab supplies the reusable commands. Use [dataset declarations](datasets.md) to
lock and prepare explicit inputs, [lab mode](lab-mode.md) to compare an authored
change, and [result reports](result-reports.md) to inspect retained evidence.
Recipes may live in any local directory or repository; Workshop, GitHub and an
internal runner are not execution prerequisites.

The relocated microlab is a workflow example. Metadata validation and synthetic
tests do not establish fluent stories, useful model quality, actual training or
accelerator support. Consult the recipe's declared evidence and limitations.
