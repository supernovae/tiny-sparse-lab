# MODEL-0 historical guide

The [original MODEL-0 guide](https://github.com/supernovae/kybern-workshop/blob/16da51d1e04a88d737f631297d96fcd1627bd13d/provenance/lab/docs/model-0.md) is preserved unchanged
in Kybern Workshop, alongside its historical experiment records. See the
[file disposition record](historical-guide-retirement.json) for its source
revision and exact byte identity.

This is a pointer to historical evidence. Absolute host paths and commands in the
original describe the recorded environment; they do not establish that payloads
exist on this machine, that the old commands work with current Lab, or that a
rerun is approved. Preservation does not change the recorded result or supply a
new model-quality claim.

For current generic interfaces, use [checkpoint exploration](checkpoint-exploration.md),
[the local API](local-api.md) and [result reports](result-reports.md) with your own
verified checkpoint and runtime.
