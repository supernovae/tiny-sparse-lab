# DevMind v0 corpus

The [preserved original][archive] is in Kybern Workshop. Its declarations,
source review and historical limitations are archived unchanged at that commit.
The [file disposition record](../../docs/devmind-v0-retirement.json) identifies
all 32 original files and their hashes.

Historical paths `corpora/devmind-v0/<file>` map to
`provenance/lab/corpora/devmind-v0/<file>` in that Workshop commit.
This locates preserved inputs without validating historical commands for replay.

This page preserves the old documentation entry point. The archive is historical
evidence; it does not establish a current runnable port, available source
payloads, rights clearance or approval to acquire data or train.

For generic corpus authoring, see [datasets](../../docs/datasets.md) and
[corpus provenance](../../docs/corpus-provenance.md).
