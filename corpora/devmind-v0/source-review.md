## Observed acquisition and exclusions

The pinned acquisition selected 186/221/45 Kubernetes concept/task/tutorial Markdown files; 329 CPython library RST, 17 tutorial RST and **26 narrowed Python files**; 33 Go documentation Markdown and 286 Go source/test files; 101 Rust Book Markdown; 98 OpenStax train modules plus the two reserved heldout modules. Exact per-source bytes and normalized passage counts are in the [static release report](../../experiments/research/devmind-pretrain-v0/source-report.md). The CPython code selection was narrowed from an initially observed 854 paths to `Lib/pathlib/*.py`, `Lib/json/*.py`, `Lib/http/*.py`, `Lib/unittest/*.py`, excluding `Lib/http/cookies.py` (Timothy O'Malley notice) and `Lib/unittest/__init__.py` (Steve Purcell notice). The prior wide selection exposed 81 code paths with non-PSF/CNRI header notices including `_pyrepl` and `_collections_abc.py`; those bytes are not in the frozen release. This header screen does **not** prove the absence of embedded third-party material or substitute for a complete rights review.

`cnxml-text-v1` omits local figures/media and captions; rejects external media, DTDs/custom entities, and pages with no prose. Five predefined XML character escapes are accepted as ordinary text. The final release rejected `m54116`, `m54280` (unsafe entity syntax) and `m54602` (no prose); OpenStax `m54081` validation and `m54082` test survive normalization. Common Kubernetes heading/shortcode/navigation-only sections were excluded before split audit; exact cross-split duplicate groups are **zero**, while 20 same-split duplicate passages were dropped. The ignored release `audit.json` and `rejected.jsonl` retain reasons and record identities. Many generated source-QA proposals were rejected for ambiguous or unsupported literal answers; that is evidence of transform selectivity, not omitted from the audit.

Go source header sampling showed selected files using `The Go Authors` notice and BSD root; CPython selected header screen found no distinct non-PSF/CNRI notice after narrowing. Kubernetes Hugo shortcodes and links, external citations in OpenStax, and possible embedded terms remain review items. Until individual content and attribution obligations are resolved, treat this research release as a **local candidate**, despite the upstream root declarations' `redistributable` label; do not publish source bytes or train a claimed rights-cleared model.
