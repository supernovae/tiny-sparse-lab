# DevMind v1 selected-source review (pilot candidate)

This is a **private, metadata-reconstruction-only candidate**, not approval to fit a tokenizer, train a model, redistribute source text, or publish weights. The frozen release is `devmind-v1@8b98f4da39438a62c2334312a6aff071af95e647008a7e4e4ddf1df62d3e97df`. Its source declarations are version 2, pin eight upstream Git commits plus four owned v2 synthetic generators, and place each source family wholly in one split. Acquire, build and freeze completed in `sparselab-work/experiments/devmind-pretrain-v1/`; source bytes remain ignored/private. The versioned source manifests, `license-report.json`, per-file acquisition SHA-256 inventories, lineage and rejected records live under `sparselab-work/experiments/devmind-pretrain-v1/corpora/devmind-v1/releases/<release-id>/`. Earlier DevMind v0 releases and audits are not superseded or relabeled.

At the selected exact pins, 2,077 Git files (30,415,753 raw bytes) were included after path exclusions; 204 files / 3,210,038 bytes are machine-classified `eligible`, 1,873 / 27,205,715 bytes `eligible_with_obligations`, none machine-classified `review_required`/`ineligible`. All 2,077 use `metadata_reconstruction_only`; weight-license status is `separate_analysis_required`. These categories reflect SPDX/header, pinned repository-root terms and nested Rust metadata **within the selected paths**; the zero unresolved *machine* count is not an all-file authorship/fixture/privacy review or an authorization to train. See [`rights-permissive.md`](../../experiments/research/devmind-pretrain-v1/rights-permissive.md) and [`rights-copyleft.md`](../../experiments/research/devmind-pretrain-v1/rights-copyleft.md) for the bounded survey and its explicit remaining review requirements. Source terms and model-weight implications are separate.
